# M2：公共灯迹、公开句子卡、渠道与看板

2026-11-10。作者明确要求完成 v1.1 §20 的四项 M2 功能，本文件补充本轮产品范围、数据契约与验收要求。M1 的真实关灯、恢复、句子冻结及一次性提醒规则保持原契约；M2 不介入关灯事务，也不在沉浸完成态增加浏览或分享入口。实际交付状态在本文末尾记录。

## 产品范围

- **公共灯迹**：从「我的」进入，查看最近七个已结束夜晚。北京时间 06:05 后开放上一晚汇总，避免把进行中的个人操作实时暴露。显示真实人数及合并时间段；总人数不足三人时隐藏人数和分布。每个公开时间段至少三人，稀疏相邻时间段合并；不返回任何人的身份或精确时间。页面另可显示当前账号本夜状态，该字段不属于公开投影。
- **公开句子卡**：从私人夜签详情主动生成，仅包含冻结原句、夜晚日期和品牌。随机链接 30 天有效，不包括关灯时间、用户身份或来源人。生成前明确说明公开范围。可以主动停止分享；原链接立即失效，已保存的图片和微信聊天预览无法收回。同一人同一夜只有一张卡，重试不重复创建；撤销或到期后不自动恢复或续期。
- **渠道归因**：管理员登记渠道标识与名称、启停渠道，复制带 `ref` 的通用入口或主动分享入口。首次成功保存的到达使用服务端时间，第一次来源确定后不覆盖；未登记、停用或无来源均记未知，未知也不会被后续渠道覆盖。固定 `share` 表示通用分享入口，不标记分享者。首次到达后 24 小时内产生的第一次真实关灯计为渠道激活，已有历史记录的用户不算新激活。记录到达不表示已关灯；网络失败可能漏记，不能据此宣称覆盖所有打开行为。
- **运营看板**：仅服务端确认的管理员从「我的」进入，查看近 7 / 30 夜人数、新激活、操作方式、成熟 3/7 与渠道到达/激活。未成熟用户单列，无成熟样本比例为空。排除管理员及配置的测试账号，异常或不完整数据不显示看似完整的比例。渠道窗口未成熟单列，未知来源保留未知，不把 M2 之前未采集的访问伪造为到达。

新增页面 `lights / public-card / dashboard / channels`，保留两个原生 Tab。所有页面有加载、空态、错误与重试；公开卡失效统一显示不可用，不向访客解释用户是否删除了资料。旧版好友、心语和统计函数不复用。

## 接口与数据

独立云函数 `bedtimeGrowth`，微信上下文鉴权；管理员由服务端 `NIGHT_ADMIN_OPENID_HASHES` 的 SHA-256 白名单确定，测试排除用 `NIGHT_ANALYTICS_EXCLUDE_HASHES`。两者是包含 64 位小写十六进制哈希的 JSON 字符串数组，不接受客户端指定身份或权限。管理员自动计入排除名单。未配置时不向任何账号开放管理功能，绝不把首位访问者自动变成管理员。

部署工具不能设置环境变量时，入口可读取 `bedtimeGrowth/private-config.json` 的 `adminHashes` 与 `excludeHashes`。原件保存在仓库外权限 600 的文件中，上传时复制为同为 600、已被 Git 忽略的部署副本；不进入前端包或提交。环境变量逐字段优先于文件，显式 `[]` 也优先。管理员配置格式错误时拒绝所有管理操作；排除名单格式错误时拒绝输出看板。JSON 解析失败或其他文件读取错误使入口停止加载，不静默使用旧权限。完整授权及部署步骤见[云部署](cloud-deployment.md#m2-管理员配置与部署)。

| action | 输入 | 用途 |
| --- | --- | --- |
| getLights | nightId 可选 | 最近七个结束夜晚的公开汇总和本人状态 |
| getOwnedCard | nightId | 本人的公开卡状态；无卡不自动创建 |
| createPublicCard | nightId | 为本人已有夜签主动创建唯一公开卡 |
| revokePublicCard | nightId、cardId | 撤销本人匹配的卡，重复调用安全 |
| getPublicCard | cardId | 向任意微信访客返回安全投影，失效统一不可用 |
| captureEntry | ref 可选 | 幂等记录首次到达，失败不影响关灯 |
| getGrowthAccess | 无 | 当前账号是否有管理权限 |
| getChannels | 无 | 管理员渠道列表 |
| saveChannel | code、label、enabled | 管理员登记或启停渠道 |
| getDashboard | from、to | 最多 31 个夜晚的聚合指标；不得包含未来夜晚 |

新增私有集合：`n_cards`（随机卡 ID）、`n_card_keys`（账号与夜晚的业务唯一键）、`n_attributions`（账号首访）、`n_channels`（管理员登记的渠道）。它们与原四集合均禁止客户端直读直写。原私人记录/用户摘要不因 M2 改写；公开稿与唯一键同事务，未知提交先回读业务键。公开读取同时核对原私人记录是否存在，个人删除后原卡立即不可用。

| 集合 | 文档 ID 与主要字段 | 不变量 |
| --- | --- | --- |
| n_cards | 128 位随机十六进制 cardId；uid、nightId、phraseText、sourceConfirmedAt、status、createdAt、expiresAt、可选 revokedAt | 原句从本人已确认夜签复制；仅安全投影可公开 |
| n_card_keys | SHA-256(uid + 分隔符 + nightId)；uid、nightId、cardId、status、createdAt、expiresAt、可选 revokedAt | 和公开卡同事务建立；撤销、到期不复活 |
| n_attributions | uid；uid、sourceCode、arrivedAt、attributionUntil、firstNightIdAtEntry、version=1 | 首次写入后不改来源或时间；不保存传入的无效原始 ref |
| n_channels | code；code、label、enabled、createdAt、updatedAt | code 为 2—32 位小写字母/数字/短横线/下划线，首位字母或数字；label 为 1—24 字且无首尾空白或控制字符 |

`unknown` 为保留来源，不可登记。`share` 缺少数据库登记时按内置启用渠道返回，名称固定为「句子卡分享」，时间为 0 表示系统内置；管理员可停用。停用只影响新的首次到达，不改已有归因。渠道列表只允许管理员读取，公开卡/分享路径不含分享者标识。

看板的每日人数与首次激活按 from—to 的 `nightId` 统计；3/7 纳入首次激活夜在该区间内的用户，A 至 A+6 共七夜，A+6 的次日 06:00 后才成熟。渠道到达按 `resolveNight(arrivedAt)` 归入同一范围，24 小时归因窗口为 `[arrivedAt, attributionUntil)`。渠道 `activations` 包含已经转化但尚未满 24 小时的到达；`conversionRate` 只用成熟到达中的转化人数除以成熟到达数，未成熟到达单列，分母为零时返回 null。历史已激活账号仍可计一次新采集的到达，但不能计渠道新激活；M2 之前未采集的访问不补造。

汇总采用可重复执行的读取重算，不创建统计定时器。固定查询上界，按 `_id` 稳定游标分批读取并在前后核对条数。灯迹对单夜最多读取 10,000 条；看板对用户、全部夜签和首访各最多完整读取 10,000 条，渠道登记最多 1,000 条。看板固定起始 serverNow，核对记录与首末摘要，并在其他读取结束后再次核对用户摘要；发现不完整、读取期间变化或超限时明确报错，不展示部分人数或比例。这是带一致性检查的重算，不是跨集合数据库快照；忙碌期间可能需要重新读取。此规模界限是首版保护，达到后需要补充分片或封账方案，不用未经验证的增量水位累加。

## 隐私与维护

本人删除扩展为六个私人集合：`n_users / n_nights / n_events / n_cards / n_card_keys / n_attributions`。先核对本人、暂停使用、取消待发提醒并等在途结束，再重新导出、预演与执行，最后逐集合回读。原三集合维护清单不可自动升级为六集合授权；须生成新版清单。`n_phrases / n_channels` 不属于个人删除范围。

公开卡只是可撤销的访问入口，不承诺撤回已缓存或转存的内容；分享动作由用户点击触发。归因不记录接收人、分享关系、自由文本或昵称。关于页同步说明公开汇总、主动分享、来源统计及删除范围。

30 天到期表示链接不再可访问，不表示已自动物理删除卡文档；私人删除仍会清除本人卡、唯一键和归因。当前没有新增过期卡清理定时器，不能声称存在自动清理。每周原始事件清理仍按原维护指南由项目所有者执行。

## 验收要求

- 公共数据：0/1/2 人不公开；3 人及稀疏跨桶正确合并；00:00、06:05 日期切换；非法/未结算日期拒绝；完整分页、上限与并发变化不报部分统计；本人字段不混入他人投影。
- 公开卡：无记录不能生成；同夜并发和丢回执只有一个 ID；其他账号不能撤销；访客无身份/精确时间；撤销、30 天到期、原记录删除后不可用；后台晚到不更新旧页面。
- 渠道：首次到达去重；无效来源归未知；已激活用户不成为新激活；24 小时边界；管理员/测试账号排除；用户不能伪造管理权限。
- 看板：成熟与未成熟 3/7、空分母、时间范围、摘要一致性、无来源数据；所有响应只有聚合结果；普通账号直接调用管理动作仍拒绝。
- 页面：四页在微信模拟器实际打开，覆盖空态、有数据、长句、错误、失效和管理员拒绝；检查分享路径只含随机卡 ID 或渠道码。受控样例与真实云验收分开记录。
- 完成 `yarn verify`、`yarn build:release`、云函数依赖准备；部署新函数和集合后分别回读权限与接口。公开发布仍由作者决定。
- 隔离云验收由 `scripts/night-growth-cloud-qa.mjs` 准备仓库外受控包与私有 session；prepare 不部署，run / cleanup / retire 绑定该 session 的环境。run 失败仍清理，只有逐项回读为空才能停用，最终实际调用须返回 RETIRED；流程见云部署文档。
