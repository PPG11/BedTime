## 用户决定与当前边界

用户已完成 iPhone 体验，并反馈 Android 简单测试没有问题，明确要求进入下一阶段。冻结标准留白 800ms、常规字号、系统无衬线、正常动效；声音首次默认关闭，由使用者开启，震动默认开启。减少动效选项保留，为直接黑色 800ms 后直接出句。原型“正常确认 250ms”只是模拟响应，正式操作没有固定成功延迟。

作者另明确：不必特别关注极短等极端屏幕，后续以大多数主流 iPhone / Android 竖屏结构为验收重点；保留基础适配，不再扩大极端尺寸测试。

Android 只记为用户报告的简测，详细型号、系统 / 微信版本、OLED / LCD、静音 / 外部音频、锁屏与连续睡前使用记录尚未提供，不把开发放行记成全项真机通过。M0 过程保留于 [历史记录](refactor-m0-review.md)。

云环境仍按用户先前说明的只读范围处理。`getState` 会幂等创建用户，因此本轮不对真实环境调用新业务接口；使用离线构建与可注入的本地服务检查。没有上传、建集合、修改规则 / 索引、清理旧资源或发布。

## 当前实现

| 范围 | 实现与边界 |
| --- | --- |
| 新入口 | 今晚 / 我的两个 Tab 与关于页；移除 M0 实验页、模拟确认控制器和会话参数 |
| 统一时间 | 北京时间 20:00—次日 06:00，含开始、不含结束；nightId 正午翻页，午夜仍属同夜；两端使用同一测试场景 |
| 服务端单夜记录 | 新 `bedtimeNight`；以微信上下文 OPENID 鉴权；唯一文档 `uid_nightId`，从请求拒绝额外身份 / 日期状态字段 |
| 幂等与事务 | 先读原记录，读空后进事务再读；仅新建检查当前窗口。冻结当夜句子、私人快照、用户首末夜摘要一起保存；已有结果始终返回原时间、方式与句子 |
| 异常恢复 | 不确定提交结果时，只有实际读到原记录才返回 `created:false`；否则保持未知。客户端 8 秒后提供原夜核对；查空不说失败，明确重试仍提交原夜 |
| 前台恢复 | 重新显示先恢复普通页和 Tab，再鉴权读取；已有 / 恢复结果不补播。身份、上下文、变更和交互代际隔离旧响应；旧夜迟到响应不倒退新夜时钟或页面 |
| 缓存与偏好 | 冷启动不展示旧私人历史；确认后的内存回执可带未刷新说明。恢复标记与偏好按 v11 + userId 隔离，未持久保存完整历史。偏好串行、合并最新选择；失败回读权威值并显示未保存 |
| 演示 | 独立本地分支，固定第一句，始终标注，不提交 / 上报 / 震动；结束返回普通首页。真实与演示共用 800ms 留白参数 |
| 页面 | 普通回执、失败、未知结果、设置与关于；首页固定可用视口，短屏收起重复信息，极短回执底部操作并排；设置与关于允许自然滚动 |

核心动作只有 `getState / closeLight / getNight / setPrefs`，对应 `n_users / n_nights / n_phrases`。三个集合的客户端规则均为禁止直读直写，文件为 [night-database-rules.json](../cloudfunctions/night-database-rules.json)。当前按文档 ID 读写，不需要自定义索引。身份通过 `wx-server-sdk.getWXContext()` 获取，调用链依据 [CloudBase 官方说明](https://docs.cloudbase.net/recipes/add-cloud-function-wechat-miniprogram)；平台实测仍是联调项。

30 句轮换沿规格候选池，第 5、28 句等仍需首发前编辑审核。冻结稿与私人句子快照不会因后来修改源池而重算。旧 home / friends / profile 和云函数暂留供后续替换，不在当前路由或启动链路，无双写、无迁移。

## 本地验证

- 使用 Node.js 22、Yarn Classic；`yarn install --frozen-lockfile` 完成，无新增前端运行时依赖。
- `ENABLE_CLOUD=false yarn verify`：类型检查、109 项测试、离线原生构建通过；之后的样式调整另行构建并在模拟器复核。
- 后端覆盖并发建档 / 双提交、跨 06:00 与正午的已有记录优先、事务冲突重试重新取时、部分失败回滚、提交回执丢失、句子冻结、不同账号、请求字段与偏好合并。
- 客户端覆盖冷启动身份、并发读、旧读覆盖写、切身份的在途提交 / 偏好、5 分钟过期、8 秒未知态、查空与明确重试、后台完成、跨夜晚到、恢复不播放、偏好串行与失败回读。新增“先查空、后刷新查到”与“旧夜查询晚于新夜刷新”两个竞态用例。
- 原生模块加载器分别运行离线与受控云响应模式，执行全部注册页生命周期，无 Node 全局、裸包或目录补全依赖。服务测试检查响应结构、归属夜晚、网络 / 业务错误及超时；旧业务测试只回归保留源码。
- 事务数据库替身具有隔离快照、冲突重试、回滚和丢失回执注入；它不证明实际 CloudBase 事务配置或性能。
